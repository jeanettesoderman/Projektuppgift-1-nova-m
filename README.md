# Nova M Music Studio

Nova M Music Studio är en fiktiv musikstudio som erbjuder specialskriven musik för video, digitalt innehåll och visuella projekt.

Webbplatsen är skapad som projektuppgift i kursen Webbutveckling DDT224G vid Mittuniversitetet. Målet har varit att bygga en komplett, responsiv webbplats med tydlig struktur, en egen visuell tilltalande, behaglig stil och JavaScriptfunktioner som gör sidan mer interaktiv.

## Om webbplatsen

Webbplatsen består av fyra sidor:

- Home
- Services
- About
- Contact

Designen har en mörk och stämningsfull stil med turkosa detaljer och bilder som passar musik och kreativt arbete.

På Services sidan finns information om de tjänster som studion erbjuder samt en FAQ som öppnas och stängs med JavaScript.

På Contact sidan finns ett kontaktformulär med egen validering i JavaScript.

Webbplatsen är även anpassad för mindre skärmar och har en hamburgermeny på mobil.

## Teknik

Projektet är byggt med:

- HTML
- CSS
- JavaScript

Jag har arbetat med responsiv design, Flexbox, CSS Grid, validering av formulär och JavaScript för interaktiva funktioner.
